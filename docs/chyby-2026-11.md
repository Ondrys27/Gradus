## Co se změnilo v zachytávání

Všechna pravidla šumu jsou v jednom souboru `src/features/errors/alerts/noise.ts` (`noiseRuleOf`), test `noise.test.ts` má u každého pravidla i skutečnou chybu, která projít musí. Kontroluje je prohlížeč před odesláním (`send-client-error.ts`), server před zápisem (`capture.ts`) i `POST /api/client-error` (staré verze prohlížeče):

| Pravidlo | Co se nezapíše | Proč to neschová skutečnou chybu |
|---|---|---|
| `abortedRequest` | „aborted“, AbortError, zrušený fetch | jen přesné znění zrušení, ne „aborted while …“ |
| `connectionLost` | Connection closed., Failed to fetch, Load failed, NetworkError | jen offline, při odchodu ze stránky nebo na dev serveru |
| `browserExtension` | chyba, jejíž horní rámec je skript rozšíření (chrome-/moz-/safari-extension://) | rozšíření hlouběji v zásobníku nevadí, chyba aplikace se zapíše |
| `browserNotice` | ResizeObserver loop, „Script error.“ | jen přesná znění |
| `staleClient` | ChunkLoadError, Loading chunk failed, Failed to fetch dynamically imported module, Failed to find Server Action | prohlížeč se místo zápisu jednou potichu obnoví na novou verzi (`stale-client.ts`); stejná chyba do minuty po obnovení už se zapíše |
| `malformedAddress` | URIError: URI malformed, Failed to decode param (boti) | jen tato znění |
| `devBundler` | manifest Turbopacku, modul po HMR, chybějící NextIntlClientProvider | jen na `next dev` (NODE_ENV development), v produkci se zapíše |

`errorText` u vyhozené věci, která není Error, nově píše její druh a zprávu („PostgrestError: …“, „unknown (Response)“) místo holého „unknown“.
